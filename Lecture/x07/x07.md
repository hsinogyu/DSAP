# 덱

## 정의와 성질

### 정의
- 양쪽 끝에서 삽입과 삭제가 전부 가능한 자료구조
- Double Ended Queue

### 성질
- 원소의 추가: O(1)
- 원소의 제거: O(1)
- 제일 앞/뒤의 원소 확인이 O(1)
- 제일 앞/뒤가 아닌 나머지 원소들의 확인/변경이 원칙적으로 불가능
    - **참고: STL deque에서는 인덱스로 접근 가능**

---
## 기능과 구현

### 구현
```cpp
#include <bits/stdc++.h>
using namespace std;

const int MX = 1000005;
int dat[2 * MX + 1]; // 덱은 양쪽 모두 삽입/삭제가 가능해서 양쪽으로 확장해야함
int head = MX, tail = MX;

void push_front(int value) {
    dat[--head] = value;
}

void push_back(int value) {
    dat[tail++] = value;
}

void pop_front() {
    head++;
}

void pop_back() {
    tail--;
}

int front() {
    return dat[head];
}

int back() {
    return dat[tail - 1];
}

int main(void) {

    return 0;
}
```

## STL deque

### 예제
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    deque<int> DQ;

    DQ.push_front(10); // 10
    DQ.push_back(50); // 10 50
    DQ.push_front(24); // 24 10 50

    for (auto x : DQ) {
        cout << x << ' ';
    }

    cout << DQ.size() << '\n'; // 3

    if (DQ.empty()) {
        cout << "DQ is empty" << '\n';
    } else {
        cout << "DQ is not empty" << '\n';
    }

    DQ.pop_front(); // 10 50
    DQ.pop_back(); // 10

    cout << DQ.back() << '\n'; // 10

    DQ.push_back(72); // 10 72

    cout << DQ.front() << '\n'; // 10

    DQ.push_back(12); // 10 72 12
    DQ[2] = 17; // 10 72 17

    DQ.insert(DQ.begin() + 1, 33); // 10 33 72 17 DQ에서는 이터레이터 +n이 가능함
    DQ.insert(DQ.begin() + 4, 60); // 10 33 72 17 60
    
    for (auto x : DQ) {
        cout << x << ' ';
    }

    DQ.erase(DQ.begin() + 3); // 10 33 72 60

    cout << DQ[3] << '\n'; // 60

    DQ.clear(); // DQ의 모든 원소 제거

    return 0;
}
```
- size()
- push_front(value)
- push_back(value)
- pop_front()
- pop_back()
- front()
- back()
- empty()
- [idx]: 인덱스로 접근 가능 / 단, 해당 인덱스에 값이 할당이 되어있어야함
- insert(iter + N, value): iter+N 위치에 삽입 / deque는 iter+N 연산이 가능함
- erase(iter + N): iter+N 위치 원소 삭제
- clear(): DQ의 모든 원소 제거

### 주의사항
- **덱이 비어있을 경우 front() / back() / pop_front() / pop_back() / [idx] / erase(iter)을 호출하면 runtime error가 발생함**
- push/pop: O(1)
- insert/erase: O(N)
- **배열과 같은 느낌으로 사용하고 싶은면 vector를 사용하는 것이 추천됨**

## 연습문제

### BOJ 10866번: 덱
```cpp
#include <bits/stdc++.h>
using namespace std;

void test() {
    deque<int> DQ;
    int n; cin >> n;
    for (int i = 0; i < n; i++) {
        string command; cin >> command;
        if (command == "push_front") {
            int value; cin >> value;
            DQ.push_front(value);
        } else if (command == "push_back") {
            int value; cin >> value;
            DQ.push_back(value);
        } else if (command == "pop_front") {
            if (DQ.empty()) {
                cout << -1 << '\n';
            } else {
                cout << DQ.front() << '\n';
                DQ.pop_front();
            }
        } else if (command == "pop_back") {
            if (DQ.empty()) {
                cout << -1 << '\n';
            } else {
                cout << DQ.back() << '\n';
                DQ.pop_back();
            }
        } else if (command == "size") {
            cout << DQ.size() << '\n';
        } else if (command == "empty") {
            cout << (int)DQ.empty() << '\n';
        } else if (command == "front") {
            if (DQ.empty()) {
                cout << -1 << '\n';
            } else {
                cout << DQ.front() << '\n';
            }
        } else if (command == "back") {
            if (DQ.empty()) {
                cout << -1 << '\n';
            } else {
                cout << DQ.back() << '\n';
            }
        }
    }
}

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    test();

    return 0;
}
```
