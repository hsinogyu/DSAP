# BFS

## 알고리즘 설명

### Flood Fill
- 색 채우기 기능
- 어떻게 구현할 수 있을까?

### BFS(Breadth First Search)
- 다차원 배열에서 각 칸을 방문할 때 너비를 우선으로 방문하는 알고리즘

---
## 예시

### 순서
1. 시작하는 칸을 큐에 넣고, 방문했다는 표시를 남김
2. 큐에서 원소를 꺼내어 그 칸에 상하좌우로 인접한 칸에 대해 3번을 진행
3. 해당 칸을 이전에 방문했다면 아무것도 하지 않고, 처음으로 방문했다면 방문했다는 표시를 남기고 해당 칸을 큐에 삽입
4. 큐가 빌 때가지 2번을 반복

### 시간 복잡도
- 모든 칸이 큐에 1번씩 들어가므로(방문할 경우 아무것도 하지 않기 때문) 시간 복잡도는 칸이 N개일 때 O(N)

### STL 소개
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(void) {
    pair<int, int> t1 = make_pair(10, 13);
    pair<int, int> t2 = {4, 6} // C++ 11
    cout << t2.first << ' ' << t2.second << '\n';
    if (t2 < t1) {
        cout << "t2 < t1";
    }
}
```
- utitliy 헤더에 있음
- first / second로 접근할 수 있음
- 대소관게가 설정되어있음
    - first를 비교
    - second를 비교
- **BFS 구현 시 큐에 좌표를 넣어야할 때 사용함**

### 코드
```cpp
#include <bits/stdc++.h>
using namespace std;

#define X first
#define Y second

int board[502][502];
bool vis[502][502];

int n = 7, m = 8;

int dx[4] = {1, 0, -1, 0};
int dy[4] = {0, 1, 0, -1};

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    queue<pair<int, int>> Q;

    // 시작점을 방문했다는 표시를 남기고, 큐에 삽입
    vis[0][0] = true;
    Q.push({0, 0});

    while (!Q.empty()) {
        pair<int, int> cur = Q.front(); Q.pop();
        cout << '(' << cur.X << ", " << cur.Y << ") -> ";
        
        for (int dir = 0; dir < 4; dir++) {
            int nx = cur.X + dx[dir];
            int ny = cur.Y + dy[dir];

            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (vis[nx][ny] == true || board[nx][ny] != 1) continue;

            vis[nx][ny] = true;
            Q.push({nx, ny});
        }
    }

    return 0;
}
```
- 1: 갈 수 있는 곳 / 0: 갈 수 없는 곳
- dx[] / dy[] => {x, y}의 집합
- 현재 좌표 지점으로 상하좌우를 탐색
    - 경계값을 넘었으면 걸러내기
    - 이미 방문했거나, 갈 수 없는 곳이면 걸러내기
    - 방문하지 않고, 갈 수 있는 곳이라면 방문표시 후, 큐에 삽입

### 주의할 점
- 시작점에 방문했다는 표시를 남기지 않는 경우
- 큐에 넣을 때 방문했다는 표시를 하는 대신 큐에 빼낼 때 방문했다는 표시를 남김
    - 같은 칸이 큐에 여러 번 들어가게 되어서 시간 초과나 메모리 초과가 날 수 있음
- 이웃한 원소가 범위를 벗어났는지에 대한 체크를 잘못한 경우

### BOJ 1926번: 그림
```cpp
#include <bits/stdc++.h>
using namespace std;

int board[502][502];
int vis[502][502];
int N, M;

int dx[4] = {0, 1, 0, -1};
int dy[4] = {1, 0, -1, 0};

void init_board() {
    for (int i = 0; i < 502; i++) {
        fill(board[i], board[i] + 502, 0);
        fill(vis[i], vis[i] + 502, 0);
    }

    cin >> N >> M;
    for (int x = 0; x < N; x++) {
        for (int y = 0; y < M; y++) {
            int input;
            cin >> input;
            board[x][y] = input;
        }
    }
}

int BFS(int x, int y) {
    int size = 0;

    queue<pair<int, int>> Q;

    vis[x][y] = 1;
    Q.push({x, y});

    while (!Q.empty()) {
        pair<int, int> cur = Q.front(); Q.pop();
        size++;

        for (int dir = 0; dir < 4; dir++) {
            int nx = cur.first + dx[dir];
            int ny = cur.second + dy[dir];

            if (nx < 0 || nx >= N || ny < 0 || ny >= M) continue;
            if (vis[nx][ny] == 1 || board[nx][ny] == 0) continue;

            vis[nx][ny] = 1;
            Q.push({nx, ny});
        }
    }

    return size;
}

void test() {
    int cnt = 0;
    int mx = 0;

    for (int x = 0; x < N; x++) {
        for (int y = 0; y < M; y++) {
            if (board[x][y] == 1 && vis[x][y] != 1) {
                int breadth = BFS(x, y);
                if (mx < breadth) {
                    mx = breadth;
                }
                cnt++;
            }
        }
    }

    cout << cnt << '\n' << mx << '\n';
}

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init_board();
    test();

    return 0;
}
```
- 상하좌우로 연결된 그림의 크기를 알아내기
    - 큐에서 몇번 꺼냈는지 확인하면 됨
- 도화지에 있는 모든 그림을 찾아내기
    - 이중 for문을 돌면서 1이면서 방문하지 않은 경우 시작점으로 판단
    - 1이면서 방문하지 않은 경우 BFS()를 호출

## 응용 1 - 거리 측정

### BOJ 2178번: 미로 탐색
```cpp
#include <bits/stdc++.h>
using namespace std;

int board[502][502];
int dist[502][502];
int N, M;

int dx[4] = {1, 0, -1, 0};
int dy[4] = {0, 1, 0, -1};

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    cin >> N >> M;
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < M; j++) {
            char input;
            cin >> input;
            board[i][j] = input - '0';
        }
    }
    
    queue<pair<int, int>> Q;
    dist[0][0] = 1;
    Q.push({0, 0});

    while (!Q.empty()) {
        pair<int, int> cur = Q.front(); Q.pop();
        
        for (int dir = 0; dir < 4; dir++) {
            int nx = cur.first + dx[dir];
            int ny = cur.second + dy[dir];

            if (nx < 0 || nx >= N || ny < 0 || ny >= M) continue;
            if (dist[nx][ny] != 0 || board[nx][ny] == 0) continue;

            dist[nx][ny] = dist[cur.first][cur.second] + 1;
            Q.push({nx, ny});
        }
    }

    cout << dist[N - 1][M - 1] << '\n';

    return 0;
}
```
- 시작점과의 최단 거리를 측정할 수 있음
- 방문하지 않았다면 dist[cur.first][cur.second] + 1을 넣어주면됨

## 응용 2 - 시작점이 여러 개일 때

### BOJ 7576번: 토마토
```cpp
#include <bits/stdc++.h>
using namespace std;

int box[1002][1002];
int N, M;
queue<pair<int, int>> Q;

int dx[4] = {1, 0, -1, 0};
int dy[4] = {0, 1, 0, -1};

void init_box() {
    for (int i = 0; i < 1002; i++) {
        fill(box[i], box[i] + 1002, 0);
    }

    while (!Q.empty()) {
        Q.pop();
    }

    cin >> M >> N;
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < M; j++) {
            int input;
            cin >> input;
            box[i][j] = input;
            if (input == 1) {
                Q.push({i, j});
            }
        }
    }
}

void bfs() {
    while (!Q.empty()) {
        pair<int, int> cur = Q.front(); Q.pop();

        for (int dir = 0; dir < 4; dir++) {
            int nx = cur.first + dx[dir];
            int ny = cur.second + dy[dir];

            if (nx < 0 || nx >= N || ny < 0 || ny >= M) continue;
            if (box[nx][ny] > 0 || box[nx][ny] == -1) continue;

            box[nx][ny] = box[cur.first][cur.second] + 1;
            Q.push({nx, ny});
        }
    }
}

int check_box() {
    int ans = 0;
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < M; j++) {
            if (box[i][j] > ans) {
                ans = box[i][j];
            }

            if (box[i][j] == 0) {
                return 0;
            }
        }
    }
    return ans;
}


int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init_box();
    bfs();
    cout << check_box() - 1 << '\n';

    return 0;
}
```
- 아이디어: 그냥 큐에 시작점을 전부 넣으면 동시에 하는 것과 같은 효과를 볼 수 있음

## 응용 3 - 시작점이 두 종류일 떄

### BOJ 4179번: 불!
```cpp
#include <bits/stdc++.h>
using namespace std;

char board[1002][1002];
int dist1[1002][1002];
int dist2[1002][1002];
int R, C;

queue<pair<int, int>> Q1;
queue<pair<int, int>> Q2;

int dx[4] = {1, 0, -1, 0};
int dy[4] = {0, 1, 0, -1};

void init_board() {
    while (!Q1.empty()) {
        Q1.pop();
    }

    while (!Q2.empty()) {
        Q2.pop();
    }

    cin >> R >> C;
    for (int i = 0; i < R; i++) {
        fill(dist1[i], dist1[i] + C, -1);
        fill(dist2[i], dist2[i] + C, -1);
        for (int j = 0; j < C; j++) {
            char input;
            cin >> input;
            board[i][j] = input;
            if (input == 'F') {
                dist1[i][j] = 0;
                Q1.push({i, j});
            }

            if (input == 'J') {
                dist2[i][j] = 0;
                Q2.push({i, j});
            }
        }
    }
}

void bfs_f() {
    while (!Q1.empty()) {
        pair<int, int> cur = Q1.front(); Q1.pop();
        
        for (int dir = 0; dir < 4; dir++) {
            int nx = cur.first + dx[dir];
            int ny = cur.second + dy[dir];

            if (nx < 0 || nx >= R || ny < 0 || ny >= C) continue;
            if (board[nx][ny] == '#' || dist1[nx][ny] > -1) continue;

            dist1[nx][ny] = dist1[cur.first][cur.second] + 1;
            Q1.push({nx, ny});
        }
    }
}

void bfs_j() {
    while (!Q2.empty()) {
        pair<int, int> cur = Q2.front(); Q2.pop();
        
        for (int dir = 0; dir < 4; dir++) {
            int nx = cur.first + dx[dir];
            int ny = cur.second + dy[dir];

            if (nx < 0 || nx >= R || ny < 0 || ny >= C) {
                cout << dist2[cur.first][cur.second] + 1 << '\n';
                return;
            }
            if (board[nx][ny] == '#' || dist2[nx][ny] > -1) continue;
            if (dist1[nx][ny] != -1 && dist1[nx][ny] <= dist2[cur.first][cur.second] + 1) continue;

            dist2[nx][ny] = dist2[cur.first][cur.second] + 1;
            Q2.push({nx, ny});
        }
    }

    cout << "IMPOSSIBLE" << '\n';
}

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init_board();  
    bfs_f();
    bfs_j();  

    return 0;
}
```
- 핵심(놓치지 쉬운 포인트)
    - 불이 닿지 않는 곳이 있을 수 있음. 즉 불의 시간을 담는 dist1을 -1로 초기화하고, -1이라면 불이 닿지 않는 곳이므로 지훈이가 갈 수 있는 곳이라고 판단
        - 왜냐하면 J >= F 일때 갈 수 없는 곳이라고 판단하는데 애초에 닿지 않으면 -1로 되어있어서 무조건 J >= F가 성립되는 문제가 발생할 수 있음
    - dist1 <= dist2에서 지훈이는 cur.X, cur.Y로 비교를 해야함(nx, ny는 -1이기 때문)

### 이런 문제의 주의할 점
- 현재 문제는 지훈이의 이동은 불의 이동에 영향을 받지만, 불의 이동은 지훈이의 이동의 영향을 받지 않아서 불만 먼저 전파를 시키는게 가능함
- 근데 만약, 시작점 A, B가 있고 서로의 행동에 영향을 주는 경우, 어느 하나를 먼저 하는게 불가능함

## 응용 4 - 1차원에서의 BFS

### BOJ 1697번: 숨바꼭질
```cpp
#include <bits/stdc++.h>
using namespace std;

int N, K;

int dist[100002];
int dx[3] = {-1, 1, 2};

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    fill(dist, dist + 100002, -1);

    cin >> N >> K;
    queue<int> Q;
    dist[N] = 0;
    Q.push(N);        

    while (!Q.empty()) {
        int cur = Q.front(); Q.pop();

        for (int dir = 0; dir < 3; dir++) {
            int nx = (dir != 2) ? cur + dx[dir] : cur * dx[dir];
            
            if (nx < 0 || nx > 100000) continue;
            if (dist[nx] > -1) continue;

            dist[nx] = dist[cur] + 1;
            Q.push(nx);
        }
    }

    cout << dist[K] << '\n';

    return 0;
}
```
- 아이디어
    - 전파를 한다가 핵심
    - 원하는 위치로 최단 거리로 이동하게 됨

### 함정
- 언니와 동생의 위치가 0 ~ 100_000 사이라고 했지. 그 이상, 그 이하를 지나가면 안된다는 조건은 없음
- 즉, 바깥으로 나갔다가 다시 안으로 들어올 수도 있음

- 음수에서 나갔다 오는건 최단 거리가 될 수 없음
    - 뒤로 가는 건 x-1 밖에 없어서 한 칸씩만 이동할 수 있기 때문

- 100_000이후로 나갈 수는 있지만 그 이후로는 -1만 계속해야함
    - 아무리 멀리가도 200_000을 넘지 않음
    - 따라서 0 ~ 200_000을 사이에서 BFS를 돌리면 안정적임

- 근데 이 문제에서는 100_000을 나가는 것 자체가 손해라는 것을 알 수 있음
    - *2를 하고 -1를 할바에야 -1를 먼저하고 *2를 하는 것이 효율적

> 멋대로 가정하고 풀면 안됨
