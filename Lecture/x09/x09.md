# BFS

## 알고리즘 설명

### Flood Fill
- 색 채우기 기능
- 어떻게 구현할 수 있을까?

### BFS(Breadth First Search)
- 다차원 배열에서 각 칸을 방문할 때 너비를 우선으로 방문하는 알고리즘

---
## 예시

### 순서
1. 시작하는 칸을 큐에 넣고, 방문했다는 표시를 남김
2. 큐에서 원소를 꺼내어 그 칸에 상하좌우로 인접한 칸에 대해 3번을 진행
3. 해당 칸을 이전에 방문했다면 아무것도 하지 않고, 처음으로 방문했다면 방문했다는 표시를 남기고 해당 칸을 큐에 삽입
4. 큐가 빌 때가지 2번을 반복

### 시간 복잡도
- 모든 칸이 큐에 1번씩 들어가므로(방문할 경우 아무것도 하지 않기 때문) 시간 복잡도는 칸이 N개일 때 O(N)

### STL 소개
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(void) {
    pair<int, int> t1 = make_pair(10, 13);
    pair<int, int> t2 = {4, 6} // C++ 11
    cout << t2.first << ' ' << t2.second << '\n';
    if (t2 < t1) {
        cout << "t2 < t1";
    }
}
```
- utitliy 헤더에 있음
- first / second로 접근할 수 있음
- 대소관게가 설정되어있음
    - first를 비교
    - second를 비교
- **BFS 구현 시 큐에 좌표를 넣어야할 때 사용함**

### 코드
```cpp
#include <bits/stdc++.h>
using namespace std;

#define X first
#define Y second

int board[502][502];
bool vis[502][502];

int n = 7, m = 8;

int dx[4] = {1, 0, -1, 0};
int dy[4] = {0, 1, 0, -1};

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    queue<pair<int, int>> Q;

    // 시작점을 방문했다는 표시를 남기고, 큐에 삽입
    vis[0][0] = true;
    Q.push({0, 0});

    while (!Q.empty()) {
        pair<int, int> cur = Q.front(); Q.pop();
        cout << '(' << cur.X << ", " << cur.Y << ") -> ";
        
        for (int dir = 0; dir < 4; dir++) {
            int nx = cur.X + dx[dir];
            int ny = cur.Y + dy[dir];

            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            if (vis[nx][ny] == true || board[nx][ny] != 1) continue;

            vis[nx][ny] = true;
            Q.push({nx, ny});
        }
    }

    return 0;
}
```
- 1: 갈 수 있는 곳 / 0: 갈 수 없는 곳
- dx[] / dy[] => {x, y}의 집합
- 현재 좌표 지점으로 상하좌우를 탐색
    - 경계값을 넘었으면 걸러내기
    - 이미 방문했거나, 갈 수 없는 곳이면 걸러내기
    - 방문하지 않고, 갈 수 있는 곳이라면 방문표시 후, 큐에 삽입

### 주의할 점
- 시작점에 방문했다는 표시를 남기지 않는 경우
- 큐에 넣을 때 방문했다는 표시를 하는 대신 큐에 빼낼 때 방문했다는 표시를 남김
    - 같은 칸이 큐에 여러 번 들어가게 되어서 시간 초과나 메모리 초과가 날 수 있음
- 이웃한 원소가 범위를 벗어났는지에 대한 체크를 잘못한 경우

### BOJ 1926번: 그림
```cpp
#include <bits/stdc++.h>
using namespace std;

int board[502][502];
int vis[502][502];
int N, M;

int dx[4] = {0, 1, 0, -1};
int dy[4] = {1, 0, -1, 0};

void init_board() {
    for (int i = 0; i < 502; i++) {
        fill(board[i], board[i] + 502, 0);
        fill(vis[i], vis[i] + 502, 0);
    }

    cin >> N >> M;
    for (int x = 0; x < N; x++) {
        for (int y = 0; y < M; y++) {
            int input;
            cin >> input;
            board[x][y] = input;
        }
    }
}

int BFS(int x, int y) {
    int size = 0;

    queue<pair<int, int>> Q;

    vis[x][y] = 1;
    Q.push({x, y});

    while (!Q.empty()) {
        pair<int, int> cur = Q.front(); Q.pop();
        size++;

        for (int dir = 0; dir < 4; dir++) {
            int nx = cur.first + dx[dir];
            int ny = cur.second + dy[dir];

            if (nx < 0 || nx >= N || ny < 0 || ny >= M) continue;
            if (vis[nx][ny] == 1 || board[nx][ny] == 0) continue;

            vis[nx][ny] = 1;
            Q.push({nx, ny});
        }
    }

    return size;
}

void test() {
    int cnt = 0;
    int mx = 0;

    for (int x = 0; x < N; x++) {
        for (int y = 0; y < M; y++) {
            if (board[x][y] == 1 && vis[x][y] != 1) {
                int breadth = BFS(x, y);
                if (mx < breadth) {
                    mx = breadth;
                }
                cnt++;
            }
        }
    }

    cout << cnt << '\n' << mx << '\n';
}

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init_board();
    test();

    return 0;
}
```
- 상하좌우로 연결된 그림의 크기를 알아내기
    - 큐에서 몇번 꺼냈는지 확인하면 됨
- 도화지에 있는 모든 그림을 찾아내기
    - 이중 for문을 돌면서 1이면서 방문하지 않은 경우 시작점으로 판단
    - 1이면서 방문하지 않은 경우 BFS()를 호출

## 응용 1 - 거리 측정

### BOJ 2178번: 미로 탐색
```cpp
#include <bits/stdc++.h>
using namespace std;

int board[502][502];
int dist[502][502];
int N, M;

int dx[4] = {1, 0, -1, 0};
int dy[4] = {0, 1, 0, -1};

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    cin >> N >> M;
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < M; j++) {
            char input;
            cin >> input;
            board[i][j] = input - '0';
        }
    }
    
    queue<pair<int, int>> Q;
    dist[0][0] = 1;
    Q.push({0, 0});

    while (!Q.empty()) {
        pair<int, int> cur = Q.front(); Q.pop();
        
        for (int dir = 0; dir < 4; dir++) {
            int nx = cur.first + dx[dir];
            int ny = cur.second + dy[dir];

            if (nx < 0 || nx >= N || ny < 0 || ny >= M) continue;
            if (dist[nx][ny] != 0 || board[nx][ny] == 0) continue;

            dist[nx][ny] = dist[cur.first][cur.second] + 1;
            Q.push({nx, ny});
        }
    }

    cout << dist[N - 1][M - 1] << '\n';

    return 0;
}
```
- 시작점과의 최단 거리를 측정할 수 있음
- 방문하지 않았다면 dist[cur.first][cur.second] + 1을 넣어주면됨
