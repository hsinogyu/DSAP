# 배열

## 정의와 성질

### 배열
- 메모리 상에 원소를 연속하게 배치한 자료구조
- 자료구조로써의 배열에서는 길이를 동적으로 늘리고 줄일 수 있음

### 배열의 성질
- O(1)에 k번재 원소를 확인/변경 가능
- 추가적으로 소모되는 메모리의 양이 거의 없음
- Cache hit rate가 높음(메모리 상 연속적)
- 메모리 상에 연속한 구간을 잡아야해서 할당에 제약이 걸림

## 기능과 구현

### 배열의 연산
- 임의의 위치에 있는 원소를 확인/변경: O(1)
- 원소를 끝에 추가: O(1)
- 마지막 원소를 제거: O(1)

- 임의의 위치에 원소를 추가: O(N)
    - 중간에 원소를 추가하게 되면 중간+1의 원소를 전부 한 칸씩 뒤로 이동해야함
- 임의의 위치에 원소를 제거: O(N)
    - 중간에 원소를 삭제하게 되면 중간+1의 원소를 전부 한 칸씩 앞으로 이동해야함

### 정리
- 임의의 위치에 있는 원소를 확인/변경: O(1)
- 원소를 끝에 추가: O(1)
- 마지막 원소를 제거: O(1)
- 임의의 위치에 원소를 추가/임의의 위치의 원소 제거: O(N)

### 사용 팁 - 배열 초기화
```cpp
int a[21];
int b[21][21];

// 1. memset
memset(a, 0, sizeof a);
memset(b, 0, sizeof b);

// 2. for
for (int i = 0; i < 21; i++) {
    a[i] = 0;
}
for (int i = 0; i < 21; i++) {
    for (int j = 0; j <21; j++) {
        b[i][j] = 0;
    }
}

// 3. fill
fill(a, a + 21, 0);
for (int i = 0; i < 21; i++) {
    fill(b[i], b[i] + 21, 0);
}
```
- for / fill 추천

## STL vector

### 예제
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(void) {
    vector<int> v1(3, 5); // {5, 5, 5}
    cout << v1.size() << '\n'; // 3
    v1.push_back(7); // {5, 5, 5, 7}

    vector<int> v2(2); // {0, 0}
    v2.insert(v2.begin() + 1, 3); // {0, 3, 0}

    vector<int> v3 = {1, 2, 3, 4}; // {1, 2, 3, 4}
    v3.erase(v3.begin() + 2); // {1, 2, 4}

    vector<int> v4;
    v4 = v3;
    cout << v4[0] << v4[1] << v4[2] << '\n'; // 124
    v4.pop_back(); // {1, 2}
    v4.clear(); // {}

    return 0;
}
```
- 임의의 위치에 있는 원소를 확인/변경: v[idx]: O(1)
- 원소를 끝에 추가: v.push_back(value): O(1)
- 마지막 원소를 제거: v.pop_back(): O(1)
- 임의의 위치에 원소를 추가/임의의 위치의 원소 제거: v.insert(iter, value) / v.erase(iter): O(N)
    - push_front(value) / pop_front(): O(N)임을 매우 주의!!

- **vector의 대입 연산은 깊은 복사가 일어남**

### 배열 vs vector
- 동적으로 길이가 늘어나거나 줄어들어야한다면 vector를 사용하는 것이 좋음
- 고정적인 길이의 경우 배열을 사용하는 것이 좋음

### 원소 순회
```cpp
vector<int> v1 = {1, 2, 3, 4, 5, 6};

// 1. range-based for loop (since C++11)
for (int e : v1) {
    cout << e << ' ';
}

for (int& e: v1) {  // 원본이 e에 들어감 - 여기서 e를 바꾸면 진짜로 바뀜
    cout << e << ' ';
}

// 2. not bad
for (int i = 0; i < v1.size(); i++) {
    cout << v[i] << ' ';
}

// 3. WRONG
for (int i = 0; i <= v1.size() - 1; i++) {
    cout << v[i] << ' ';
}
```
- WRONG: v1.size()는 unsigned int를 반환함 => 0일 경우 -1을 하게되면 언더플로우가 발생하여 문제가 될 수 있음

## 연습문제

### 사용하는 경우
- 데이터를 자주 바꾸지 않고, 그냥 쌓아두고 싶을 때 활용할 수 있음

### BOJ 10808: 알파벳 갯수
```cpp
#include <bits/stdc++.h>
using namespace std;

int arr[26];

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string input;
    cin >> input;

    for (char c : input) {
        arr[c - 'a']++;
    }

    for (int i = 0; i < 26; i++) {
        cout << arr[i] << ' ';
    }

    return 0;
}
```
- 시간 복잡도: O(N)
- 아이디어: 배열의 인덱스를 알파벳으로 사용하고 값을 나온 횟수로 사용

### 0x01강의 연습문제
```cpp
#include <bits/stdc++.h>
using namespace std;

int func2(vector<int> v, int n) {
    int hap[100] = {0, };

    for (int i = 0; i < n; i++) {
        if (hap[100 - v[i]] == 1) {
            return 1;
        }
        hap[v[i]] = 1;
    }

    return 0;
}

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cout << func2({1, 52, 48}, 3) << '\n';
    cout << func2({50, 42}, 2) << '\n';
    cout << func2({4, 13, 63, 87}, 4) << '\n';

    return 0;
}
```
- 시간 복잡도: O(1)
- 아이디어: 합이 100인 두 쌍이 있기만하면되므로 순차적으로 탐색하면서 나왔다면 1 아니라면 0으로 표시
