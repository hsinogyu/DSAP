# 스택의 활용(수식의 괄호 쌍)

## 수식의 괄호 쌍이란?

### 문제
- 32 - {6 - (2 + 4) * 7}: 정상적인 수식 O
- 5 + {6 - (12 + 4 } * 7): 정상적인 수식 X

### 괄호만 봤을 때
- {()}: O
- {(}): X

### 정의
- 괄호 쌍이 맞게 닫혀있는지 확인하는 문제를 수식의 괄호 쌍 문제라고 함

---
## 문제 해결을 위한 관찰

### 괄호의 종류가 1개인 경우
- (())()(): O
- ))((): X
- ()())((): O
- 도출 과정
    - 제일 안쪽부터 짝맞추기를 해서 지워나감
    - 또는 닫는 괄호의 갯수가 여는 괄호의 갯수를 넘지 않아야한다는 사실

### 괄호의 종류가 2개인 경우
- ({}): O
- ({)}: X
- 도출 과정
    - 제일 안쪽부터 짝맞추기를 해서 지워나감
    - 배열로 구현할 경우 최대 N번 중간에 있는 원소의 삭제가 발생하기 때문에 O(N^2)
    - 연결 리스트로 구현할 경우 O(N)
    - 스택으로도 풀 수 있음 => 관찰이 필요함

### 스택으로 풀기위한 관찰
- 문자열을 앞에서부터 읽어나갈 때, 닫는 괄호는 남아있는 괄호 중에서 가장 최근에 들어온 여는 괄호와 짝을 지어 없애버리는 명령이라고 생각해도 됨
- 스택에 여는 괄호가 들어오면 넣고, 닫는 괄호를 만날 시, 스택의 가장 위쪽에 있는 괄호와 쌍이 맞으면 지움 / 아니면 X 그리고 문자열을 끝까지 읽고 나서 스택이 비어있으면 O 아니면 X

### 올바르지 않은 괄호 쌍 1
- ({)}
- 스택
    - (
    - ({
    - ({) => 올바르지 않다는 것을 알 수 있음

### 올바르지 않은 괄호 쌍 2
- ({}
- 스택
    - (
    - ({
    - ({} => (
    - ( => 스택이 비어있지 않으므로 올바르지 않다는 것을 알 수 있음

### 올바르지 않은 괄호 쌍 3
- ()}
- 스택
    - (
    - () => 
    - } => 스택이 비어있으므로 올바르지 않다는 것을 알 수 있음

---
## 문제 해결 방법

### 과정
- 여는 괄호가 나오면 스택에 추가
- 닫는 괄호가 나왔을 경우,
    - 스택이 비어있으면 올바르지 않은 괄호 쌍
    - 스택의 top이 짝이 맞지 않는 괄호일 경우 올바르지 않은 괄호 쌍
    - 스택의 top이 짝이 맞는 괄호일 경우 pop
- 모든 과정을 끝낸 후
    - 스택에 괄호가 남아있으면 올바르지 않는 괄호 쌍
    - 스택에 괄호가 남아있지 않으면 올바른 괄호 쌍

## 연습문제

### BOJ 4949번: 균형잡힌 세상
```cpp
#include <bits/stdc++.h>
using namespace std;

string test(string input) {
    stack<char> S;
    for (char c : input) {
        if (c == '(') {
            S.push(c);
        } else if (c == '[') {
            S.push(c);
        } else if (c == ')') {
            // 스택이 비어있을 때, no
            if (S.empty()) {
                return "no";
            }

            // 스택이 비어있지 않은데, 맞지 않을 때, no
            if (S.top() != '(') {
                return "no";
            }

            S.pop();
        } else if (c == ']') {
            // 스택이 비어있을 때, no
            if (S.empty()) {
                return "no";
            }

            // 스택이 비어있지 않은데, 맞지 않을 때, no
            if (S.top() != '[') {
                return "no";
            }

            S.pop();
        }
    }

    if (S.empty()) {
        return "yes";
    } else {
        return "no";
    }
}

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    while (true) {
        string input;
        getline(cin, input);
        if (input == ".") break;

        cout << test(input) << '\n';
    }

    return 0;
}
```
- 만약 empty()를 확인하기 전에 top()을 호출하면 절대 안됨
- empty() || top() 순으로 해도 됨
    - 단 top() || empty()는 안됨
