# 연결 리스트

## 정의와 성질

### 정의
- 원소를 저장할 때, 다음 원소가 있는 위치를 같이 저장하는 자료구조
- 원소의 위치는 여기저기 흩어져있음

### 성질
- k번째 원소를 확인/변경: O(k)
    - 연결 리스트 구조 상 다음 원소의 위치만 가지고 있기 때문에 순차적으로 탐색해야함
- 임의의 위치에 원소를 추가/임의 위치의 원소 제거: O(1)

- 메모리 상에 연속해있지 않아 Cache hit rate가 낮지만 할당이 쉬움

### 종류
- 단일 연결 리스트
    - 각 원소가 다음 원소의 위치만 들고 있는 연결 리스트

- 이중 연결 리스트
    - 각 원소가 다음/이전 원소의 위치를 들고 있는 연결 리스트
    - C++ STL의 list는 이중 연결 리스트

- 원형 연결 리스트
    - 끝의 원소가 처음의 원소와 연결되어 있는 연결 리스트
    - 단일/이중 리스트의 끝의 원소는 보통 null을 가리키고 있음

### 배열 vs 연결 리스트
| - | 배열 | 연결 리스트 |
| --- | --- | --- |
| k번째 원소의 접근 | O(1) | O(k) |
| 임의 위치에 원소 추가/제거 | O(N) | O(1) |
| 메모리 상의 배치 | 연속적 | 불연속적 |
| 추가적으로 필요한 공간 | 없음 | 원소의 위치를 담을 공간 필요 O(N) |

- 참고: 연결 리스트도 임의 위치에 원소 추가/제거를 하기 위해서는 접근해야하기 때문에 O(k)가 걸림
    - 단, 위치를 알고 있을 경우에는 O(1)이 필요함

## 기능과 구현

### 제공되는 연산
- 임의의 위치에 있는 원소를 확인/변경: O(N)
    - 인덱스로 접근하는 배열과 달리 첫 원소부터 순차적으로 탐색해서 찾아가야함

- 임의의 위치에 원소를 추가: O(1)
    - 연결 정보를 추가만 해주면 됨
    - 단, 중간에 원소를 추가하기 위해서는 O(k)번만큼 탐색 후 추가해야하기 때문에 사실상 O(k)

- 임의의 위치의 원소를 제거: O(1)
    - 연결 정보를 끝어내고 다시 연결해주면 됨
    - 원소 삭제 이후 메모리 할당도 제거

### 정리
- 임의의 위치에 있는 원소를 확인/변경: O(N)
- 임의의 위치에 원소를 추가/임의의 원소 제거: O(1)

### 사용되는 곳
- 메모장의 커서를 옮기는 작업
    - 커서가 가르키는 위치에 글자를 추가하거나 삭제하는 작업
    - 위치를 알고 있다면, 추가/제거가 O(1)으로 매우 효율적임

## STL list

### 예제
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    list<int> L = {1, 2}; // 1, 2
    list<int>::iterator t = L.begin();
    L.push_front(10); // 10, 1, 2: O(1)

    cout << *t << '\n'; // 1

    L.push_back(5); // 10, 1, 2, 5: O(1)
    L.insert(t, 6); // t가 가리키는 곳 앞에 6을 삽입 10, 6, 1, 2, 5: O(1), 위치를 알고 있음
    t++; // t가 가리키는 값은 2가 됨
    t = L.erase(t); // t가 가리키는 값을 제거, 그 다음 원소인 5의 위치를 반환. 10, 6, 1, 5

    cout << *t << '\n'; // 5

    for (auto i : L) {
        cout << i << ' ';
    }
    cout << '\n';
    for (list<int>::iterator it = L.begin(); it != L.end(); ++it) {
        cout << *it << ' ';
    }
    cout << '\n';

    return 0;
}
```
- erase(iter): 제거한 원소의 다음 원소 위치(iter)를 반환: O(1)
- push_front(value) / push_back(value): O(1)
- insert(iter, value): 앞에 삽입 후 삽입한 원소의 위치를 반환: 위치를 넘겨주었기 때문에 O(1)

## 연습 문제

### BOJ 1406번: 에디터
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string first_input_string;
    cin >> first_input_string;

    list<char> L;
    for (int i = 0; i < first_input_string.size(); i++) {
        L.push_back(first_input_string[i]);
    }
    list<char>::iterator cursor = L.end();

    int n;
    cin >> n;
    
    for (int i = 0; i < n; i++) {
        char command;
        cin >> command;

        if (command == 'L') {
            // 커서가 문장의 맨 앞이면 무시됨
            if (cursor == L.begin()) continue;

            // 커서를 왼쪽으로 한 칸 옮김
            cursor--;
        } else if (command == 'D') {
            // 커서가 문장의 맨 뒤이면 무시됨
            if (cursor == L.end()) continue;

            // 커서를 오른쪽으로 한 칸 옮김
            cursor++;
        } else if (command == 'B') {
            // 커서가 문장의 맨 앞이면 무시됨
            if (cursor == L.begin()) continue;

            // 커서 왼쪽에 있는 문자를 삭제함
            cursor = L.erase(--cursor);
        } else if (command == 'P') {
            char input;
            cin >> input;
            
            // 문자를 커서 왼쪽에 추가함
            L.insert(cursor, input);
        }
    }

    for (list<char>::iterator it = L.begin(); it != L.end(); ++it) {
        cout << *it;
    }

    return 0;
}
```
- 시간 복잡도: O(N + M)
- 아이디어 커서+문자를 한 묶음로 보고 위치를 확인

### 손코딩 문제 1
- 문제: 원형 연결 리스트 내의 임의의 노드 하나가 주어졌을 때 해당 List의 길이를 효율적으로 구하는 방법

- 정답: 동일한 노드가 나올 때까지 계속 다음 노드로 가면 됨
    - 공간 복잡도: O(1)
    - 시간 복잡도: O(N)

### 손코딩 문제 2
- 문제: 중간에 만나는 두 연결 리스트의 시작점들이 주어졌을 때 만나는 지점을 구하는 방법

- 정답: 
    - 두 시작점 각각에 대해서 끝까지 진행시켜서 각각의 길이를 구함
    - 그 후 다시 두 시작점으로 돌아와서 더 긴쪽을 둘의 차이만큼 앞으로 먼저 이동시켜놓고
    - 두 시작점이 만날 때까지 두 시작점을 동시에 한 칸씩 전진

### 손코딩 문제 3
- 문제: 주어진 연결 리스트 안에 사이클이 있는지 판단하라

- 정답: 플로이드 사이클 찾기 알고리즘
    - 공간 복잡도: O(1)
    - 시간 복잡도: O(N)
    - 한 칸씩 출발하는 커서와 두 칸씩 출발하는 커서를 동일한 시작점에서 출발하면
    - 사이클이 있을 경우 두 커서나 반드시 만나게 됨
