## STL과 함수 인자

### STL을 함수 인자로 넘길 떄
```cpp
void func1(vector<int> v) {
    v[10] = 7;
}

int main(void) {
    vector<int> v(100);
    func1(v);
    cout << v[10];
}
```
- 답은 0
- 배열을 복사해서 넘기므로 func1의 vector랑 main의 vector랑 서로 다른 주소 공간
- 단, 내부 값의 경우 얕은 복사가 이루어짐

### STL을 함수 인자로 잘못 넘기면
```cpp
bool cmp(vector<int> v1, vector<int> v2, int idx) {
    return v1[idx] > v2[idx];
}
```
- 시간 복잡도: O(N)
    - v1, v2를 원본으로부터 복사하는 과정이 필요함 => O(N)

```cpp
bool cmp(vector<int>& v1, vector<int>& v2) {
    return v1[idx] > v2[idx];
}
```
- 시간 복잡도: O(1)

## 표준 입출력

### 공백을 포함한 문자열 한 줄을 입력 받는 방법(단순히 cin이나 scanf를 사용하면 안됨)
```cpp
string s;
getline(cin, s);
cout << s;
```

### cin, cout에서 시간초과를 방지하기 위한 방법
```cpp
int main(void) {
    ios::sync_with_stdio(false);
}
```

- scanf/printf를 쓰는 C stream과 cin/cout를 쓰는 C++ stream은 서로 기본적으로 동기화되어있음
- cin/cout만 사용할거라면 굳이 동기화로 인한 시간을 잡아먹을 필요가 없어서 이를 강제로 끊음
- 주의: cout / printf를 섞어쓰면 절대 안됨

```cpp
int main(void) {
    cin.tie(nullptr);
}
```
- 기본적으로 cin 명령을 수행하기 전에 cout 버퍼를 비워줌
- 근데 채점 서버는 출력 글자만 확인하기 때문에 굳이 꼬여도 문제가 없음
