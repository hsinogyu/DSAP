# 큐

## 정의와 성질

### 정의
- 한 쪽 끝에서 원소를 넣고, 반대쪽 끝에서 원소를 뺄 수 있는 자료구조
- FIFO(First In First Out) / LILO(Last In Last Out)

### 성질
- 원소의 추가: O(1)
- 원소의 제거: O(1)
- 제일 앞/뒤 원소 확인: O(1)
- 제일 앞/뒤가 아닌 나머지 원소들의 확인/변경이 원칙적으로 불가능

### 용어
- 원소가 추가되는 위치: rear
- 원소가 제거되는 위치: front

---
## 기능과 구현

### 구현
```cpp
#include <bits/stdc++.h>
using namespace std;

const int MX = 1000005;
int dat[MX];
int rear = 0, front = 0;

void push(int value) {
    dat[rear++] = value;
}

void pop() {
    front++;
}

int front() {
    return dat[front];
}

int rear() {
    return dat[rear - 1];
}

int main(void) {

    return 0;
}
```

## STL queue

### 예제
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    queue<int> Q;

    Q.push(10); // 10
    Q.push(20); // 10 20
    Q.push(30); // 10 20 30

    cout << Q.size() << '\n'; // 3

    if (Q.empty()) {
        cout << "Q is empty" << '\n';
    } else {
        cout << "Q is not empty" << '\n';
    }

    Q.pop(); // 20 30
    
    cout << Q.front() << '\n'; // 20
    cout << Q.back() << '\n'; // 30

    Q.push(40); // 20 30 40

    Q.pop(); // 30 40

    cout << Q.front() << '\n'; // 30

    return 0;
}
```
- size(): 큐의 크기 반환
- push(value): 원소를 삽입
- pop(): front() 원소를 삭제
- front(): 가장 처음으로 들어간 원소를 반환
- back(): 가장 마지막으로 들어간 원소를 반환
- empty(): 비어있는지 확인

### 주의사항
- **스택과 마찬가지로 큐가 비어있을 경우 pop() / front() / back()을 호출하면 runtime error 발생함**

## 연습문제

### BOJ 10845번: 큐
```cpp
#include <bits/stdc++.h>
using namespace std;

void test() {
    queue<int> Q;
    int n; cin >> n;
    for (int i = 0; i < n; i++) {
        string command; cin >> command;
        if (command == "push") {
            int value; cin >> value;
            Q.push(value);
        } else if (command == "pop") {
            if (Q.empty()) {
                cout << -1 << '\n';
            } else {
                cout << Q.front() << '\n';
                Q.pop();
            }
        } else if (command == "size") {
            cout << Q.size() << '\n';
        } else if (command == "empty") {
            cout << (int)Q.empty() << '\n';
        } else if (command == "front") {
            if (Q.empty()) {
                cout << -1 << '\n';
            } else {
                cout << Q.front() << '\n';
            }
        } else if (command == "back") {
            if (Q.empty()) {
                cout << -1 << '\n';
            } else {
                cout << Q.back() << '\n';
            }
        }
    }
}

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    test();

    return 0;
}
```
