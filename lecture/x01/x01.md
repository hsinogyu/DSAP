# 기초 코드 작성 요령 1

## 시간, 공간 복잡도

### 컴퓨터의 연산 처리 속도
- 1초에 약 3~5억 개 정도의 연산 처리 가능

### 시간 복잡도(Time Complexity)
- 입력의 크기와 문제를 해결하는데 걸리는 시간의 상관관계

### 빅오 표기법(Big-O Notation)
- 주어진 식을 값이 가장 큰 대표항만 남겨서 나타내는 방법
    - O(N): 5N + 3
    - O(N^2): N^2 + 2N + 4
    - O(NlgN): NlgN + 30N + 10
    - O(1): 5, 16, 36

### N의 크기에 따른 허용 시간 복잡도
| N의 크기 | 허용 시간 복잡도 |
| --- | --- |
| N <= 11 | O(N!) |
| N <= 25 | O(2^N) |
| N <= 100 | O(N^4) |
| N <= 500 | O(N^3) |
| N <= 3_000 | O(N^2lgN) |
| N <= 5_000 | O(N^2) |
| N <= 1_000_000 | O(NlgN) |
| N <= 10_000_000 | O(N) |
| 그 이상 | O(lgN), O(1) |

### 공간 복잡도(Space Complexity)
- 입력의 크기와 문제를 해결하는데 필요한 공간의 상관관계
- **512MB == 1.2억 개의 int**
